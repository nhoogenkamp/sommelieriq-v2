SommelierIQ

SommelierIQ is a full-stack restaurant wine recommendation platform designed to help customers find suitable wines from a restaurant's own wine list based on one or multiple selected dishes.

The application provides a customer-facing food and wine recommendation interface together with restaurant-specific administration. Restaurant users can manage wines, food items and sauces, import data through CSV files, use AI-assisted wine data generation, manage users through role-based access control and provide customers with direct access through a restaurant-specific QR code.

The recommendation system remains rule-based and compares food and wine characteristics including colour, body, tannin, acidity and sweetness. When multiple dishes are selected, SommelierIQ combines the individual pairing scores to identify wines with the strongest overall match.

Live Application
